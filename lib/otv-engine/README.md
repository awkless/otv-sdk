# OTV Analysis Engine Library

A basic library that implements an OTV analysis engine for water flow.

## Install

Follow the instructions in the top-level README of the project. The `otvscan`
binary is built with the rest of the active codebase by default.

## Usage

See `examples/` directory for usage examples.

## Acknowledgements

The `otvscan` binary is based on the work done by [Arsal-Hanif, Andrea Conti,
Luca Foianesi, et al.][otv-paper] for OTV analysis on embedded hardware. The
original code used by their paper can be found [here][otv-code].
